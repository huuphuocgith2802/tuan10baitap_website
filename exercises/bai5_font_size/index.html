Bài 5: Thay Đổi Kích Thước Văn Bản

Bấm nút "Phóng to" hoặc "Thu nhỏ" để tăng/giảm kích thước chữ 2px.

Cỡ chữ hiện tại: 16px

"DOM (Document Object Model) cho phép JavaScript truy xuất và thay đổi các thuộc tính CSS như fontSize, color, display theo thời gian thực để tạo trải nghiệm người dùng sống động."
